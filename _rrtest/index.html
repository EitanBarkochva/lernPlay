צריך להגדיר Firebase

כדי לאפשר התחברות עם גוגל ושמירת ז'יטונים בענן, מלא את הפרטים בקובץ firebase-config.js.

1. צור פרויקט ב-console.firebase.google.com
2. הפעל Authentication → Google
3. צור Firestore Database
4. רשום אפליקציית Web והעתק את ה-firebaseConfig
5. הדבק ב-firebase-config.js ודחוף לגיט
6. הוסף eitanbarkochva.github.io ל-Authorized domains

המדריך המלא נמצא ב-README של הריפו.
