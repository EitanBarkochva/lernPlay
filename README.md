# 🎮 משחק לימודי — חופש גדול

אפליקציית אינטרנט לימודית בעברית (RTL) בסגנון סופר מריו: מורה/הורה יוצר משחק
שאלות ומקבל קוד, התלמיד נכנס עם הקוד, משחק, אוסף מטבעות זהב על תשובות נכונות,
ובסוף נשמר דוח מפורט. בנוי ב-**HTML, CSS, JavaScript בלבד** (ללא ספריות),
עם מסד נתונים **Supabase** (גישה דרך REST API ב-`fetch`).

## הפעלה
פותחים את `index.html` בדפדפן — זהו. האפליקציה מחוברת ל-Supabase בענן,
ואם אין הגדרות חיבור היא עובדת מקומית עם `localStorage`.

## מבנה הקבצים
| קובץ | תפקיד |
|------|-------|
| `index.html` | כל המסכים (SPA) |
| `style.css` | עיצוב צבעוני RTL, רספונסיבי |
| `app.js` | לוגיקת המסכים, טפסים, שאלות, דוחות, בחירת משחק |
| `game.js` | מנוע משחק סופר מריו על Canvas (תנועה, קפיצה, שלבים, צלילים) |
| `data.js` | שכבת נתונים — מתאם לסכמת Supabase + גיבוי localStorage |
| `supabase_setup.sql` | הרשאות RLS לטבלאות |
| `SUPABASE.md` | מדריך חיבור למסד הנתונים |
| `GAME_CODES.md` | רשימת כל קודי המשחקים לפי כיתה ונושא |

## תוכן קיים
41 משחקים, 1161 שאלות (כולן נבדקו):
- **חשבון** כיתות א–ו (28 משחקים, 30 תרגילים כל אחד) — נוצרו אלגוריתמית
- **אנגלית / עברית / מדעים / תורה** כיתות א–ג (12 משחקים)

## פיצ'רים
- יצירת משחק (מורה/הורה) עם שאלות וקוד אקראי
- מסך "בחר משחק" עם חיפוש וסינון לפי כיתה
- משחק מריו: 30 תרגילים מתחלקים למספר שלבים, מטבעות כסף וזהב, צלילים
- מצב "שאלות בלי משחק" (quiz)
- דוח תלמיד מפורט + דוחות מורה לפי קוד משחק
- כפתור מייל למורה (`mailto:`)
- מבנה גמיש: כיתות א–יב, מקצועות וסוגי משחק נוספים בעתיד

## הערה על אבטחה
המפתח ב-`data.js` הוא **anon key** של Supabase — מיועד לצד הלקוח וזה תקין.
האבטחה נעשית דרך מדיניות RLS במסד הנתונים (`supabase_setup.sql`).
